# Roadmap (com evidência)

## Planejado explicitamente

O README menciona como evoluções futuras:

- benchmarking entre providers
- comparação de custo e latência
- leaderboard de modelos

Esse item é **planejado** e não implementado.

## Não implementado e não reservado como roadmap

- autenticação e autorização
- persistência do backend de análises
- banco de dados
- integração de fila / jobs assíncronos
- observabilidade e métricas de produção

Esses temas não aparecem como uma roadmap formal; aparecem como ausências de implementação ou como futuras possibilidades em documentação, não como compromissos firmes.

## Status

Esta página existe apenas para preservar a distinção entre **planejado explícito** e **inferência**. Nada aqui é tratado como fact em ausência de evidência.
