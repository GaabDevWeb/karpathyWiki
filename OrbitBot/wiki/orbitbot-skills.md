# Skills

O repo OrbitBot **não** tem `.cursor/skills`, `AGENTS.md` nem um skill registry.

Skills em `~/.agents/skills`, `AGENTS/` e `CursorSKILLS/` são para o agente de desenvolvimento (Cursor). **Não** são consumidas pelo runtime WhatsApp.

Comandos admin (`/ai`, `/backup`, `/historico`, `/reset`) são comandos do bot, não skills Cursor.

Status: skills runtime no OrbitBot = **ausentes**.
